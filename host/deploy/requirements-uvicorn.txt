# host/deploy/requirements-uvicorn.txt — P22A2, the one hash-locked Python requirement set the
# deploy image installs, and nothing else.
#
# uvicorn is an IMAGE requirement here, never a distribution requirement. host/pyproject.toml still
# declares `dependencies = []`, so the host wheel stays framework-independent and nothing is added
# to the host distribution or to any host lock: the image, not the library, chooses its server.
#
# Every distribution below — uvicorn's own transitive set included — carries the sha256 of every
# artifact pip is allowed to install, so `pip install --require-hashes` refuses anything that is
# not byte-for-byte one of these, even if the index later serves a different file under the same
# name and version. A version range would not be a lock; a version pin without a hash would still
# trust whatever the index hands back.
#
# Resolved once against the pinned python:3.12.14 base with the pinned uv 0.11.1. To regenerate,
# from the single input line `uvicorn==0.40.0`:
#   uv pip compile --generate-hashes --no-header <input> -o host/deploy/requirements-uvicorn.txt
